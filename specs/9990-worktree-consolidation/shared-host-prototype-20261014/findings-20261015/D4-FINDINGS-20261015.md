## Canary — was failing for an independent reason (fixed)

`build/daemon.canary.mjs` (both 14/10 18:00 and first 15/10 runs) died with
`connect ENOENT` AFTER `statSync` verified the socket. Root cause: **the
socket path was 110 bytes — over the AF_UNIX `sun_path` 107-byte limit**. The
daemon's private `bind-<hash>` path (104 bytes) binds fine; the 110-byte
public name lstat/chmod/hardlinks fine, but `connect(2)` truncates and fails
with ENOENT forever. Proof: `socket-presence-repro.ts` with a 97-byte twin
path = 60/60 CONNECT-OK over 12 s in the same scratch. The coordinator's D4
probe passed because its path was short. Constraint recorded as an assert in
the canary (`socket.length <= 107`); systemd `%t` path is 47 bytes (safe).
